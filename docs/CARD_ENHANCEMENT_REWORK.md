# 카드 강화 개편 정리

작성: 2026-09-10.

지금까지 합의한 방향, 현재 CSV·코드에서 확인한 내용, 앞으로 손볼 부분을 구분한다. 후속 요청에 따라 6절의 1~6번 구현·검증을 진행한다. 자동 검증과 실제 신규 계정 플레이 측정은 구분하며, 실행 결과는 아래 관련 검증 기록에 남긴다.

## 1. 개편 목적

현재 시너지는 2성부터 사용할 수 있다. 카드 한 장을 강화하는 비용뿐 아니라 조합에 필요한 2~3장을 함께 키워야 하는 비용 때문에 첫 시너지 경험과 새 카드 교체가 늦어지는 문제가 있었다.

시너지를 1성으로 옮기면 일부 카드의 키워드 해금과 보상이 겹치고, 이후 강화의 동기가 약해질 수 있다. 따라서 **시너지 해금은 2성으로 유지하면서 2성까지의 비용을 낮춘다.** 3성은 마음에 든 주력 카드를 선택해 투자하는 구간으로 둔다.

첫 접속 후 약 1시간의 목표는 다음과 같다.

- 시너지 최소 1종, 권장 2종을 직접 구성하고 전투에서 사용한다.
- 주력 2장을 3성으로 키운다.
- 권장 최종 덱은 3성 2장 + 2성 4장이다.
- 다른 카드를 실험할 조각을 조금 남긴다.

시간은 플레이 테스트 목표다. 모든 사용자가 60분 안에 달성한다는 보장이 아니며 제한 시간이나 보상 만료 조건으로 쓰지 않는다.

## 2. 확정 방향과 현재 확인 상태

| 항목 | 개편 방향 | 2026-09-10 확인 |
|---|---|---|
| 0→1성 비용 | 조각 25 → 10 | CardEnhance CSV에 10 반영 |
| 1→2성 비용 | 조각 75 → 20 | CardEnhance CSV에 20 반영 |
| 2→3성 비용 | 조각 150 유지 | CardEnhance CSV에 150 반영 |
| 시너지 해금 | 2성 유지 | GrowthRules.FirstEvolutionLevel=3, 내부 Lv3=표시 2성 |
| 진화 외형 | 2성 1차 진화, 3성 2차 진화 유지 | GrowthRules의 진화 단계 계산 확인 |
| 키워드 해금 | 카드별 기존 조건 유지 | Card의 keywordUnlockLevel 사용 |
| 강화 성공률 | 카드·키워드 강화 100% | 서버 enhanceRules에서 1000분율 1000 반환. 현 CSV에는 성공률 열 없음 |
| 첫 시간 기본 조각 | 가이드 300 + 모험 1장 240 | 재화 배분안의 목표 예산. 실제 지급 연결·서버 반영 완료와 구분 |
| 한계돌파 | 간식 사용, 첫 시간 필수 조건에서 제외 | 기존 3단계·단계별 HP +1, 간식 1/2/3 표 유지 |

1성은 키워드를 익히는 대표 구간이지, 모든 카드가 1성에서 새 키워드를 얻는다는 뜻은 아니다. 처음부터 키워드가 있는 카드와 키워드가 없는 카드도 있으므로 화면은 해당 카드의 실제 해금 조건을 표시해야 한다.

## 3. 강화 단계별 역할

| 성급 | 사용자가 느껴야 할 변화 | 개편에서 할 일 |
|---|---|---|
| 0성 | 새 카드를 얻고 기본 역할을 파악 | 카드별 키워드·시너지와 해금 조건을 미리 확인 가능하게 안내 |
| 1성 | 적은 비용으로 첫 성장 경험 | 체력 증가와 실제로 열리는 키워드를 구분해 표시 |
| 2성 | 조합에 쓸 수 있는 카드 완성 | 시너지 해금·진화 외형을 보여주고 덱 조합 완성으로 연결 |
| 3성 | 선택한 주력 카드가 확실히 강해짐 | 체력 전후 차이·진화 외형·실전 효과를 확인하기 쉽게 표시 |

3성 비용은 2성 승급 비용의 7.5배다. 그만큼 전투에서 차이가 느껴지는지 확인해야 한다. 다만 이 문서에서 모든 카드의 3성 HP를 일괄 상향하거나 새로운 능력을 붙이기로 확정하지는 않는다.

## 4. 개편할 부분

### A. 첫 조합을 만드는 성장 순서

- 초반에는 돌보미 카드 3장을 먼저 2성으로 키우도록 안내한다.
- 해당 조합을 사용한 진행 보상으로 버섯냥을 제공한다. 기존 깜밤이와 함께 2성으로 키우면 추적까지 구성할 수 있다.
- 첫 3성은 앞서 2성으로 키운 카드 중 사용자가 선택한다. 미강화인 여섯 번째 카드를 바로 3성으로 올리는 경로는 초기 예산과 다르므로 기본 안내로 쓰지 않는다.
- 마지막 한 자리와 두 번째 3성 카드는 사용자가 선택한다.
- 특정 랜덤 팩 결과나 중복 획득을 필수 조건으로 만들지 않는다.

### B. 강화 화면의 정보와 반복 조작

아래는 화면 개편 기준이다. 후속 구현에서 강화 전 정보·가이드 추천 안내를 추가했으며 실제 Unity 화면 검수는 별도 확인 항목이다.

- 강화 전에 현재/다음 성급, 체력 전후, 비용, 강화 후 잔액을 보여준다.
- 이번 강화로 열리는 키워드·시너지·진화 외형을 실제 카드 데이터에 맞춰 표시한다. 변화가 없는 기능은 해금 보상처럼 표시하지 않는다.
- 가이드 진행 중에는 다음에 키울 카드와 해당 목표까지 필요한 비용을 찾기 쉽게 안내한다.
- 낮은 성급 여러 장을 키울 때의 이동·반복 연출 시간을 측정한다. 불필요한 반복이 확인되면 줄인다.
- 강화 실패 확률을 조절하는 UI나 실패 전제 설명이 남아 있는지 점검하고, 실제 100% 규칙과 일치시킨다.
- 다른 카드에 투자하는 행동을 막지 않는다. 단, 권장 경로를 벗어나면 가이드 목표 시점이 늦어질 수 있음을 비용 안내로 이해할 수 있게 한다.

자동 일괄 강화, 목표 성급까지 한 번에 강화, 조각 환급·카드 초기화는 아직 결정하지 않았다. 필요한 경우 별도 범위로 판단한다.

### C. 3성의 성장 체감 검증

- 카드별 hp4와 기존 키워드·시너지 조합을 기준으로 대표 전투를 비교한다.
- 2성에서 3성이 됐을 때 한 번 더 버티거나 이전에 못 잡던 적을 잡는 등 유효한 차이가 발생하는지 본다.
- 특정 카드만 3성 투자 효율이 지나치게 높아 두 에이스 선택이 고정되는지 확인한다.
- 3성 2장 덱과 2성 6장 덱 사이에 성장 체감이 생기면서, 조합·대상 선택의 의미도 유지되는지 확인한다.
- 부족한 카드만 수치 조정 후보로 뽑는다. HP 변경은 검증 후 별도로 결정한다.

랭크 AI가 플레이어 강화 직후 같은 비율로 강해지면 성장 체감을 잃기 쉽다. 적 성장 곡선은 별도 [랭크 AI 설계](RANK_AI_FIRST_HOUR_DESIGN.md)와 함께 검증하되, 이번 강화 개편에서 상대 성장 규칙을 확정하거나 수정하지 않는다.

### D. 재화 지급과 가이드의 연결

- 다음 강화 미션의 비용은 앞선 가이드·모험 보상에서 확보되도록 한다.
- 기존 튜토리얼의 무료 강화와 이미 끝낸 덱 편성·정점 클리어를 소급 인정한다.
- 특정 성급의 서로 다른 카드 수를 판정한다. 강화 버튼을 누른 횟수로 대체하지 않는다.
- 이미 클리어한 모험 정점은 재도전을 요구하지 않는다. 가이드 안내에 적힌 추천 덱을 사용했는지까지 추가 필수 조건으로 묶지 않는다.
- 가이드 보상·고정 카드 지급·중복 조각·미션 집계는 테이블 저작과 실제 지급 연결을 따로 확인한다.
- 서버가 비용을 차감하고 성장을 확정하며, 클라는 응답을 채택한다. 재요청·재접속으로 이중 차감이나 중복 강화가 발생하지 않아야 한다.

### E. 첫 시간 이후의 성장

- 신규 카드 1장을 2성으로 만드는 비용은 30조각이다. 새 조합을 시험하는 부담을 낮게 유지한다.
- 일일 직접 조각 60은 신규 카드 2장의 2성 비용이다.
- 일일 7회 + 주간 1회의 직접 조각 600은 2→3성 승급 4회분이다. 실제 성장은 새 카드 투자량에 따라 달라진다.
- 중복·룰렛은 추가 획득이다. 기대값을 필수 성장 보장량으로 취급하지 않는다.
- 키워드 강화는 에너지, 한계돌파는 해당 카드 간식을 사용한다. 첫 시간 가이드에 두 성장축을 추가 필수 과제로 넣지 않는다.

## 5. 비용과 수급 검산

| 목표 | 조각 비용 |
|---|---:|
| 카드 1장 0→2성 | 10 + 20 = 30 |
| 카드 1장 0→3성 | 10 + 20 + 150 = 180 |
| 첫 돌보미 조합 3장 2성 | 90 |
| 돌보미 3장 + 추적 2장 모두 2성 | 150 |
| 덱 6장 모두 2성 | 180 |
| 그중 2장을 추가로 3성 | 300 |
| 최종 3성 2장 + 2성 4장 | 480 |

가이드 300 + 모험 1장 240 = 기본 수급 540. 권장 덱 성장에 480을 쓰고 60이 남는다. 기존 깜밤이 무료 첫 강화를 포함하면 소비 470, 잔액 70이다.

일일·주간·패스·룰렛·중복·랭크·기존 전투 및 도감 보상은 위 기본 540에서 제외한다. 해당 보상을 추가로 받으면 총수급은 늘어난다. 3성 2장은 목표 경로의 결과이며 보유 상한이 아니다.

## 6. 작업 순서와 완료 기준

| 순서 | 할 일 | 완료 기준 |
|---|---|---|
| 1 | 현재 강화 규칙과 표시 일치 확인 | 비용 10/20/150, 2성 시너지, 카드별 키워드 해금, 강화 100%가 화면·서버에서 일치 |
| 2 | 필수 가이드·모험 보상 연결 확인 | 랜덤 획득 없이 조합 카드와 조각을 얻고 다음 미션을 진행 가능 |
| 3 | 강화 화면 안내 개선 | 비용·전후 스탯·실제 해금·미션 대상이 명확하고 반복 조작이 과하지 않음 |
| 4 | 신규 계정 첫 시간 플레이 검증 | 첫 시너지 약 20분, 두 조합 약 30분, 첫 3성 약 40분, 두 번째 3성 약 55~60분 목표 점검 |
| 5 | 3성 효율·상대 난이도 검증 | 강화 효과가 실전에서 드러나고 두 에이스 선택이 한 조합으로 고정되지 않음 |
| 6 | 실패·이탈·다른 투자 경로 검증 | 전투 패배·재접속·선행 달성·덱 변경·다른 카드 투자로 가이드가 영구 정지하지 않음 |

반드시 측정할 값은 첫 시너지 구성/실전 사용 시각, 두 번째 조합 시각, 첫·두 번째 3성 시각, 그때의 조각 수급·소비·잔액, 재도전 횟수, 강화 화면 체류 시간이다. 느린 사용자와 분산 투자 사용자의 결과도 별도로 본다.
