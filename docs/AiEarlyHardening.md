# 초반 AI 난이도 추가 상향

2026-09-16. 중후반 상향에 이어 초반도 더 어렵게 조정한 로컬 CSV 초안이다. 실제 승률·무료 성장 속도는 검증 전이다.

## 적용 기준

- 카드 자체 스탯·키워드·보상·강화 비용·해금 점수는 유지했다. 랭크 티어 6 이상과 모험 9번 이후도 이번에는 바꾸지 않았다.
- 브론즈 1(티어0): 무키워드 꿀꿀비·솜구름몽 2장만 1성. 나머지는 0성이므로 키워드와 시너지는 여전히 미활성이다.
- 브론즈 2(티어1): 전원 1성. 브론즈 3(티어2): 주력 3~4장 2성. 비늘·추적 해금 슬롯을 보존했다.
- 브론즈 4(티어3): 전원 2성. 브론즈 승급전과 실버 1~2(티어4~5): 주력 3성 2장·보조 2성 4장.
- 모험 1번은 와글도도→솜구름몽, 얼음꼬미→늪꾸리로 교체했다. 전원 0성·효과 미해금 상태를 유지하며 HP 합 18→22로 높였다.
- 모험 2~3번 전원 1성은 유지하고 4~8번은 전원 2성으로 올렸다. 모험 4번부터 시너지 조합이 작동한다.

## 반영 및 검증

- 실제 서버 파서·전투 스냅샷 생성/재채택 검증 통과: 46덱·160랭크 프로필·24모험 노드. 점수 0~1000의 상대 선택, 같은 덱의 성장 비감소, 승급전 성장≥일반전도 확인했다.

- AIDeck 1행, RankAiEncounter 28행, AdventureChapter 5행 변경.
- ID·컬럼 계약·한계돌파·강조 슬롯·등장 가중치 보존. CSV 재읽기 일치와 작업 범위 밖 행 보존 확인.
- 로컬 CSV만 수정. 서버 업로드·시트·SpecData.bytes·자동 생성 C#은 갱신하지 않았다.
- 실전 승률과 초반 이탈·반복 실패율은 미검증이다. 향후 성장 재화 공급량 확정 후 함께 조정해야 한다.
