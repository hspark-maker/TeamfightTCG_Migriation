# 카드 강화 전투 밸런스 검증

2026-09-10. `CARD_ENHANCEMENT_REWORK.md` 기준 5 담당 결과. **실제 BattleCore 173,824전과 전투별 권위 재생 대조를 완료했다. 강화 효과는 확인했지만, 에이스 선택의 비편중까지 합격으로 판단하지 않는다.** 현행 상대는 너무 쉬워 이 표본에서 강화 전후 승률이 모두 100%였다. HP·상대 성장 규칙 변경은 수행하지 않았다.

## 측정 근거와 범위

- 실행 코어: 이미 존재하는 `Library/ScriptAssemblies/TeamfightTCG.BattleCore.dll`. PDB의 전투 소스 **41/41개가 현재 파일과 체크섬 일치**. DLL SHA256 `8fc8edd3c867cd9f4edae6a800d713671415805b8c4dc9f90fd3141dcc1da6b5`.
- 기존 캡처 골든: 같은 코어로 **25 통과, 1 제외**. 제외 이유는 이전 스키마의 `boardOrder` 누락이다. 제외 벡터를 합격 건수에 넣지 않았다.
- 덱 비교 **147,456전**, 카드 40종 전체 1:1 비교 **25,600전**, 첫 장 진행 상태 비교 **768전**. 모든 전투의 명령 로그를 `BattleReplay.Run`으로 다시 실행하여 매 턴 체크포인트·최종 해시·난수 소비·승패·잔존 카드 일치 확인. 시뮬레이터 시간은 사람 플레이 시간이 아니다.
- `TryBuildField`, `BeginTurn`, `EndTurn`, `FillEmptySlots`는 코어의 실제 replay 메서드를 reflection으로 호출한다. 공격·피해·반격·회복·시너지·무쌍·처형·교활·일반 카드 강화 추가타 역시 실제 코어 호출이다. 전투력 합산식으로 승패를 대신하지 않았다.
- 카드·효과·상대·모험 수치는 현재 CSV에서 읽었다. 표시 2성=내부 Lv3, 3성=Lv4. HP는 `maxHp + hp2 + hp3 [+ hp4]`로 누적하고 카드별 키워드 해금과 진화 단계를 주입했다. 3성의 기존 일반 카드 추가타도 포함한다. 한계돌파·별도 키워드 성장 투자는 없다.
- 64개 결정론 시드, 실제 코어의 선공 추첨으로 **선공 32·후공 32**를 구성했다. 코어의 owner별 파생 스트림 셔플을 사용하며 배치를 고정하지 않는다. 쌍 비교 안에서는 시드·상대·정책·선후공을 동일하게 유지한다.
- `random`: 살아 있는 공격자와 도발 규칙을 만족하는 대상의 모든 합법 쌍에서 균등 선택. `preview`: 실제 `AttackPreview`의 처치 가능→공격자 생존→예상 순피해 순서로 선택하고 동률은 별도 AI 난수 스트림으로 추첨. 양측에 같은 정책 사용. 둘 다 실험 정책이며 Unity `EnemyAi`나 사람 숙련도를 재현하지 않는다. 멀리건은 하지 않는다.

원본 입력 해시, 15개 에이스 쌍 전부의 집계, 상대별 최고 쌍·동률, 카드별 결과, 변화 예시 명령 로그는 [results.json](../Tools/EnhancementBalanceTests/results.json)에 있다. 방법·지표 정의는 [README](../Tools/EnhancementBalanceTests/README.md), 실행은 [run.fsx](../Tools/EnhancementBalanceTests/run.fsx), 집계는 [summarize.js](../Tools/EnhancementBalanceTests/summarize.js).

가상 프로필은 메모리 실험 입력이다. 랭크 AI 설계의 확정안이나 저작·배포된 상대 프로필로 취급하지 않는다.

## 강화 전후 전투 결과

숫자는 **승률 %**, 강화 후는 15개 쌍을 같은 비중으로 평균한 값이다. 정책·프로필별 기준은 512전, 강화 후는 7,680전이다.

| 덱 | six2: random 전→후 | six2: preview 전→후 | two3: random 전→후 | two3: preview 전→후 |
|---|---:|---:|---:|---:|
| A | 84.96 → 90.59 | 84.38 → 93.84 | 73.83 → 84.61 | 64.45 → 79.87 |
| B | 83.01 → 89.95 | 83.79 → 93.18 | 70.51 → 82.63 | 64.65 → 78.67 |
| C | 82.03 → 90.79 | 84.96 → 94.43 | 67.97 → 83.44 | 62.11 → 80.09 |

`authored`에서는 A/B/C와 두 정책 모두 **기준 100%·강화 후 100%**였다. 기존 적 성장 저작값으로는 2성 덱과 3성 에이스 덱의 승률 차이가 드러나지 않는다. 따라서 현재 상대 난이도 문제를 약한 카드 HP 탓으로 해석하지 않는다. 별도 상대 설계 검토에 전달할 결과다.

승리=1·무승부=0.5·패배=0으로 놓은 평균 점수 개선도는 `six2`에서 **+5.25~9.50%p**, `two3`에서 **+10.62~17.77%p**였다. 무승부 때문에 위 승률 차이와 약간 다르다. 예를 들어 A/preview/two3의 개선은 +15.42%p, 시드 단위 95% 정규근사 구간은 **+12.81~18.04%p**다. 쌍·상대가 같은 시드를 공유하므로 7,680전을 독립 표본으로 계산하지 않았다. 이 구간은 정책·덱 선정 편향이나 다중 비교를 보정하지 않는다.

선후공을 나눠도 효과가 있었다. three-deck 평균 `preview/two3` 승률은 플레이어 선공 **66.41→81.39%**, 후공 **61.07→77.70%**였다. 양측 같은 정책이라 더 어려운 상대에서 preview가 random보다 낮은 경우도 있다. 이를 사람 숙련도 효과로 해석할 수 없다.

실제 승패 변화 예시: A 대 `deck_03/six2`, random, seed=1, 플레이어 후공. **별토리+깜밤이(3+8)**를 3성으로 올리면 9공격 후 패배·적 4장 잔존에서, 12공격 후 승리·아군 1장/HP 2 잔존으로 바뀌었다. 아군 주공격 교환에서 피해를 받고 살아남은 횟수는 0→5, 서버 재생 집계 피해량은 55→89였다. 양쪽 전체 명령 로그·해시는 results.json의 `examples`에 보존했다. 같은 공격 순서를 강제한 반사실 실험은 아니며 성장에 따른 후속 선택·난수 소비 변화도 포함한다.

## 에이스 편중과 재검토 후보

| 덱 / six2 상대 | random 최고 쌍·점수 개선 | preview 최고 쌍·점수 개선 |
|---|---|---|
| A | 파도리+깜밤이(2+8), +7.71%p | 파도리+버섯냥(2+9), +14.84%p |
| B | 파도리+깜밤이(2+8), +8.11%p | 파도리+버섯냥(2+9), +15.23%p |
| C | 버섯냥+꿈먹이(9+10), +11.33%p | 파도리+버섯냥(2+9), +13.96%p |

**정책에 따라 최고 쌍은 바뀌지만, preview에서는 3개 덱 모두 2+9가 최고였다.** A/preview/two3에서도 2+9는 +26.27%p이고, 변별력이 큰 `deck_03/04/07`에서 단독 최고였다. 쉬운 상대의 전 쌍 동률은 선택 다양성의 증거로 세지 않는다. 따라서 기준 5의 “두 에이스 선택이 한 조합으로 고정되지 않음”은 **미확정**이다. 원거리 두 장의 우세를 실제 플레이·현행 EnemyAi·다른 상대 분포로 재검증할 후보로 남긴다. 최고 쌍과 차순위의 통계적 분리를 증명한 것도 아니다.

부족한 투자 효과의 **재검토 후보**는 솜구름몽(4), 바위콩(6)을 포함하는 비원거리 조합이다. A/preview/six2의 1+4는 +3.71%p, 3+4는 +4.20%p; B의 1+6는 +2.15%p, 3+6는 +2.93%p였다. 반면 1+9·3+9는 높게 나오므로 포슬램·별토리를 단독 약체로 단정하지 않는다. 일반 카드 추가타가 이미 적용된 결과다.

실제 40종 모두를 2성 상대 40종과 1:1로 비교한 스크리닝에서는 틱톡곤(36) +3.75%p, 피닉시아(40) +5.00%p, 번개뿔(26)·모닥콩(27)·크랙몬(38) 각 +6.25%p로 변화가 작았다. 이는 **시너지·대기열을 제거한 후보 선별 결과**이며 해당 카드의 6장 덱 효율 결론이 아니다. 특히 파도리는 1:1 개선 +14.38%p지만 덱에서는 최고 쌍에 반복 등장한다. 1:1 순위로 HP를 조정하면 잘못된 결론이 될 수 있다.

대표 HP는 포슬램 12→16, 파도리 13→16, 별토리 13→17, 솜구름몽 13→16, 바위콩 14→17, 깜밤이 12→18, 버섯냥 12→16, 꿈먹이 12→19다. `hp4`가 큰 카드가 항상 최고의 투자 대상은 아니다. **이번 결과로 HP 조정안을 확정하거나 적용하지 않는다.**

## 첫 시간 오프라인 평가와 다른 담당 증거

확정 소유·실제 순차 수령·멱등성과 복구 경로의 권위 근거는 [서버 검증 보고서](ENHANCEMENT_GUIDE_VERIFICATION.md)다. 그 보고서는 실제 `TutorialStarterGrant`·`TutorialFirstCard`·`KeywordDeck` 호출로 돌보미 1·2·3·4와 깜밤이 8 확보, 실제 callable 수령으로 **가이드 300 + 모험 240 = 540**, 무료 강화 포함 소비 470·잔액 70을 확인했다. 여기에 사용한 `poolFixtureIds`는 일부 기존 팩 풀 목록이며 **확정 획득 증거가 아니다**. ID8은 별도 직접 지급을 전제로 `routeOwnedIds`에 포함한다. 버섯냥9는 가이드5 지급 뒤 사용한다.

이 담당의 보조 원장은 현재 서버 `evaluateGuideProgress`·강화 비용 파서를 메모리에서 실행한 것으로, 실제 지급 증거를 중복 주장하지 않는다. 정상 경로의 13단계 판정과 480/60, 무료 포함 470/70을 재확인했다. 선행 완성 상태, 저장·재읽기·덱 변경 후 최고 진행도 유지도 순수 함수 수준에서만 확인했다.
