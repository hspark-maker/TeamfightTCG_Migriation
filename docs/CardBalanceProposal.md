# 카드 역할·밸런스 개편 제안

> 이전 제안과 작업 기록입니다. 후속 조정으로 4장을 무키워드 카드로 전환하고 체력을 조정했습니다. 최신 CSV 반영값은 [카드 역할·등급 체력 밸런스](CardRoleBalanceApplied.md)를 따릅니다.

작성: 2026-09-16. 현재 로컬 `docs/SpecData/Card_sheet.csv`의 Live 카드 40장과 전투 코드 기준.
**아래 전체 개편안과 HP는 검토용이며 대전 검증 전 시작값이다.** 서버에 발행된 표와의 일치 여부는 이번 분석에서 확인하지 않았다.

### 후속 적용 범위

사용자 지시에 따라 새 효과 없이 미지정 항목만 `Card_sheet.csv`에 추가했다. 키워드는 솜구름몽·바위콩=도발, 우드혼·모닥콩=힐러, 꿀꿀비=교활, 번개뿔·폭탄밤=무쌍, 단풍꼬리=처형, 수정뿔루=불사이며 모두 내부 Lv2(표시 1성)에 해금된다. 시너지는 왕밤도치·단풍꼬리=유산, 모닥콩=덩치, 수정뿔루=비늘, 폭탄밤=낙인을 추가했다.

총 10장의 빈 항목만 채웠고 기존 능력, HP와 성장 수치는 유지했다. 아래의 현 상태·현재 HP 열은 추가 작업 전 기준이며, 기존 카드 재배정·체력 조정·신규 효과 제안은 적용하지 않았다. 서버 업로드와 `SpecData.bytes` 갱신도 수행하지 않았다.

## 1. 현 상태의 문제

- 키워드 미지정 9장: 솜구름몽, 바위콩, 우드혼, 꿀꿀비, 번개뿔, 모닥콩, 단풍꼬리, 수정뿔루, 폭탄밤.
- 시너지 미지정 5장: 왕밤도치, 모닥콩, 단풍꼬리, 수정뿔루, 폭탄밤. 양쪽 모두 없는 카드는 마지막 4장이다.
- 키워드가 있는 31장 중 27장은 내부 Lv2(표시 1성)에 해금된다. 기본 상태부터 사용하는 카드는 파도리·별토리·철갑몽치·마그몰 4장이다. 시너지는 내부 Lv3(표시 2성)부터 열린다. 미지정과 아직 미해금인 상태를 구별해야 한다.
- 포슬램과 별토리는 같은 힐러·돌보미인데 HP가 각각 `3/5/7/16`, `4/6/8/17`이다. 별토리가 모든 단계에서 높고 키워드도 먼저 열린다. 동일 투자 조건에서 포슬램을 선택할 이유가 약하다.
- 물방울룽과 풍선펭은 HP `2/5/7/15`, 교활·흐름, 등급, 해금 조건까지 같다. 외형 이외의 차이가 없다.
- 눈덩곰과 화르룩스도 도발·덩치, 같은 희귀 등급인데 화르룩스 HP가 전 구간 우세하다.

## 2. 개편 원칙

1. 모든 카드에 **고유 키워드 1개와 시너지 1개**를 저작한다. 신화 2장의 기존 복수 시너지는 유지하되 수치로 비용을 지불한다. 복수 키워드는 이번 안에서 추가하지 않는다.
2. 같은 시너지 안에서 막아 주는 카드, 직접 적을 잡는 카드, 교대하는 카드, 지원하는 카드를 나눈다. 같은 키워드까지 겹치는 카드는 초반형·후반형 등 명확한 성장 차이가 있어야 한다.
3. 새 키워드는 1성에 해금하고 기존 해금 조건은 유지한다. 시너지는 2성 유지. 성급을 올렸을 때의 학습 순서를 이번 밸런스 작업으로 바꾸지 않는다.
4. 공격력은 현재 HP에 기반하므로 키워드 추가와 HP 곡선을 함께 조절한다. 도발은 현재 HP의 절반으로 공격하고, 추가 생명력은 공격력에 포함되지 않는다.
5. 희귀도가 높다고 모든 면에서 우월하게 만들지 않는다. 조합의 연결이나 독특한 생존 방식으로 가치를 주되 일반 카드도 덱의 핵심 역할을 맡는다.

## 5. 특히 먼저 바꿀 카드

- **솜구름몽 → 도발·돌보미:** 회복 조합을 지키는 전열로 완성. 기본 공격력 반감까지 고려해 체력을 올린다.
- **바위콩 → 도발·덩치 / 눈덩곰 → 무쌍·덩치:** 같은 단단한 카드라도 버티는 돌과 굴러가며 주변을 때리는 눈덩이로 역할을 나눈다.
- **모닥콩 → 힐러·덩치:** 캠프의 회복 담당. 현재 무능력 고체력에서 체력을 낮추고 아군 지원 가치를 받는다.
- **수정뿔루 → 불사·비늘:** 수정이 부서진 뒤 다시 뭉치는 수호자. 불사는 기존 1회 부활이며 새 보호막 효과를 뜻하지 않는다. 설명문도 능력과 일치하게 조정할 후보다.
- **폭탄밤 → 무쌍·낙인:** 선피해와 주변 타격을 하는 폭격수. 현재 무쌍은 양옆 중 무작위 한 장만 때리며, 사망 시 폭발은 아니다.
- **물방울룽은 교활 유지 / 풍선펭은 원거리:** 교대하며 스택을 만드는 수달과 필드에 남아 누적 공격력을 쓰는 펭귄으로 나눈다.
- **우드혼 → 힐러·유산 / 루미엘크 → 힐러·포식자:** 우드혼은 숲을 남기는 지원, 루미엘크는 사냥대 유지 담당. 힐러의 실효성은 같은 회복 키워드만으로 판단하지 않고 조합 단위로 검증한다.
- **포슬램은 성장형 / 별토리는 초반형:** 둘 다 초반 가이드의 돌보미 풀을 보존하면서 체력 곡선의 우열을 뒤집는 임시 차별화다. 최종 성장에서는 다시 포슬램이 우세하므로 이것만으로 장기적인 역할 분리가 완성되지는 않는다. 최종 방향은 2차안의 보호막 키워드로 별토리를 분리하는 것을 추천한다.

## 6. 수치 조절에서 빠뜨리면 안 되는 실제 규칙

### 키워드를 붙이면 사라지는 것과 추가되는 것

- 현재 무키워드 카드는 3성에서 기본 공격 뒤 원래 기본 HP의 50%(버림)만큼 추가타를 얻는다. 키워드를 붙인 9장은 이 보너스를 잃는다. 새 키워드 자체와 새 체력 곡선을 합쳐 비교해야 한다.
- 기존 6종 키워드 강화는 키워드별 최대 HP +10을 준다. 키워드가 둘이면 합산되므로 복수 키워드 추가는 능력 두 개 이상의 상향이다.
- **불사는 키워드 강화 지원 목록에 없다.** 수정뿔루·틱톡곤·피닉시아의 표 수치는 키워드 강화 0 기준 후보일 뿐이다. 강화 10 환경에서 나머지 카드가 HP +10을 얻는 비교까지 통과해야 확정할 수 있다. 필요하면 불사 성장 지원을 별도 코드 변경으로 함께 설계한다.

### 무제한 회복·누적 조합

- 힐러는 자기 턴 시작에 다른 아군 전원 HP +1을 주며 최대 HP를 넘길 수 있다. HP 증가는 공격력도 올린다. 3힐러가 필드에 있으면 각 카드가 턴마다 다른 두 힐러에게 +2를 받는다.
- 이 안은 힐러를 3종에서 5종으로 늘리므로 힐러·도발·비늘 조합을 우선 검사한다. 과도하면 새 힐러 수를 줄이거나 회복 상한을 도입하는 별도 규칙안을 비교한다. 임의로 모든 카드 HP만 낮춰 해결하지 않는다.
- 흐름은 재등장마다 공격력이 누적되고 상한이 없다. 교활은 대기열이 있어야 작동한다. 교활 카드를 늘렸다고 항상 강해지거나 무한 반복이 된다고 단정할 수 없다.
- 원거리·포식자는 반격 없이 회복해 체력을 보존하기 쉬우므로 해롱문어를 낮은 기본 HP로 시작한다. 포식자는 기본 주 대상 피해만 흡혈하고 회복 상한은 최대 HP다.
- 낙인·처형은 선피해로 적을 약화시킨 뒤 연쇄 처치를 노릴 수 있다. 원거리와 처형을 한 카드에 함께 붙이지 않는다.
- 새 화르룩스의 4덩치 추가 생명력 +6과 처형, 새 단풍꼬리의 유산 오버힐과 처형은 반격 생존·연쇄 공격을 동시에 강화하므로 우선 검증한다.
- **표식·무적·추가생명력은 일반 카드 고유 키워드 배정 대상에서 제외한다.** 표식은 걸린 적의 반격을 없애는 불이익 상태이고, 추가생명력은 별도 수치가 필요하다. 고유 무적은 현재 소모 구현과 맞지 않는다.

### 시너지 공통 수치는 첫 비교에서 유지

카드 풀과 공통 시너지 계수를 동시에 크게 바꾸면 개선 원인을 알기 어렵다. 1차는 카드 배정·체력만 바꾸고 기존 활성 장수와 효과량을 유지한다. 특히 5장 시너지인 돌보미·흐름·낙인은 6장 덱에서 큰 투자가 필요하므로 2장 시너지와 같은 수치 기준으로 평가하지 않는다.

## 7. 검증할 덱과 통과 기준

| 대표 덱 | 구성 예시 | 확인할 것 |
|---|---|---|
| 초반 돌보미+추적 | 포슬램, 파도리, 솜구름몽, 깜밤이, 버섯냥, 별꼬리 | 돌보미 첫 단계(3장)·추적 2장 조건 충족, 기존 가이드 진행 가능 |
| 덩치+비늘 | 바위콩, 눈덩곰, 화르룩스, 모닥콩, 철갑몽치, 수정뿔루 | 4덩치+2비늘, 초반 버티기가 영구 압도인지 |
| 흐름 집중 | 물방울룽, 풍선펭, 찌릿핀, 번개뿔, 마그몰, 틱톡곤 | 5흐름 상위 단계와 6번째 흐름 카드의 선택 가치, 교대 누적 |
| 낙인+포식자 | 와글도도, 꿀꿀비, 폭탄밤, 얼음꼬미, 라이고르, 해롱문어 | 5낙인+2포식자, 신화 연결 카드와 선피해의 과도한 효율 |
| 유산+추적 | 왕밤도치, 우드혼, 대장부리, 단풍꼬리, 피닉시아, 깜밤이 | 4유산 상위 단계+2추적, 부활·사망 회복 |
| 극단 회복 | 포슬램, 별토리, 우드혼, 루미엘크, 모닥콩, 철갑몽치 | 3힐러 초기 필드, 오버힐·장기전·턴 상한 |

첫 행의 돌보미는 4장을 넣었지만 활성 단계는 3장 임계의 첫 단계다. 검증에서는 카드 해금 조건까지 충족한 2성 이상 덱으로 비교한다.

1. 같은 성장 예산으로 모든 2성, 3성 2장+2성 4장, 모든 3성 환경을 나눈다. 키워드 강화는 0/5/10으로 구분하고 불사는 지원 여부를 명시한다.
2. 선후공을 교환하고 배치·드로우 시드를 바꾼다. 같은 대상 선택 정책으로 수백 판씩 비교하되 봇 정책의 편향을 감안한다.
3. 각 대표 덱을 상대로 후보 1장을 교체했을 때 결과가 어떻게 바뀌는지 본다. 같은 역할·같은 비용의 카드가 모든 상대에게 항상 열세면 다시 설계한다.
4. 평균 승률만 보지 말고 턴 수, 유효 공격 횟수, 회복·추가생명력 사용량, 연쇄 처치, 선공 편향을 함께 본다. 평균 45~55%는 1차 선별 목표일 뿐이며 모든 상성을 50%로 맞추지는 않는다.
5. 초기 모험 고정 덱·가이드 미션·카드 획득 경로를 재검증한다. PvP 변화가 모험 난이도 변화로 그대로 번지므로 필요할 때 AI 덱/레벨을 따로 조절한다.

기존 `Tools/BattleCore`, `BattleReplay`, `BattleGoldenReplayHarness`를 검증 기반으로 재사용할 수 있다. 이번 문서 작성에서는 자동 대전이나 승률 측정을 실행하지 않았다.

## 8. 2차안: 기존 키워드만으로 개성이 부족한 카드

새 규칙을 한 번에 많이 만들기보다 다음 중 필요한 소수만 추가한다. 아래는 **미구현 효과 제안**이며 위 1차안과 동시에 적용하는 것이 아니다.

- 폭탄밤: 사망 시 인접 적 피해. 기본 HP·무쌍을 그대로 두고 추가하지 말고 무쌍을 교체한다.
- 별토리 또는 수정뿔루: 등장 시 아군 1장에게 다음 피해 1회 보호막. 기존 힐러 또는 불사와 교체한다.
- 얼음꼬미: 공격한 적의 다음 공격 피해 감소. 처형을 교체하며 영구 공격력 감소·행동 불능과는 구분한다.

규칙 변경은 클라이언트 전투와 서버 재시뮬레이션을 함께 갱신해야 한다. 표현만 얼음·폭발·보호막이라고 바꾸고 실제 효과가 없는 상태로 출시하지 않는다.
