# 멀티플레이 재접속 v1

## 지원 범위

- 멀리건 완료 후, 앱이 살아 있는 전투에서 일시적인 연결 끊김을 복구한다.
- 앱 종료·재실행, 멀리건 중 복구, 새 기기에서 이어하기는 지원하지 않는다. 전투 상태는 메모리에 보존한다.
- 프로토콜은 `p4`다. 양쪽 클라이언트에 같은 변경을 포함한 빌드가 필요하며 기존 `p3` 매칭과 분리된다.

## 동작

1. 연결 종료 또는 3초 동안 상대 통신이 없으면 재접속 상태로 진입한다. 입력과 생각 시간·통신 대기 시간을 멈추고 기존 대기 오버레이에 남은 시간을 표시한다.
2. 로컬 연결이 종료되면 새 Photon Runner로 원래 방 이름에 재입장한다. 방을 새로 생성하지 않으며 전투 데이터와 플레이어 소유 번호는 유지한다.
3. 최초 상대와 교환한 키로 새 challenge에 응답해야 변경된 Photon PlayerRef를 상대에게 연결한다.
4. 순번과 누적 ACK로 누락 메시지를 재전송하고 중복을 제거한다. 진행 중이던 공격은 해결을 마치며, 상대 카드 보충 명령은 공격·연출 동기화 이후 적용한다.
5. 양쪽 카드 보충이 끝난 체크포인트의 상태 해시와 송수신 완료 지점이 일치해야 입력을 재개한다. 상태가 다르면 경기를 종료한다.
6. 30초 유예가 끝났을 때 상대 이탈이 확인되고 내 연결이 유지되어 있으면 기존 AI 인수 경로를 사용한다. 로컬 연결 실패 또는 이탈 주체가 불명확하면 Timeout으로 무효 종료한다. 종료·AI 인수 후에는 해당 판으로 복귀하지 않는다.

설정은 `Assets/Scripts/Network/NetTimeouts.cs`, 복구 제어는 `BattleReconnect.cs`, 순서 보장·재전송은 `ReliableBattleChannel.cs`에 있다.

## 자동 검증

프로젝트 루트에서 실행한다. 설치된 프로젝트 버전의 Unity 컴파일러와 Mono를 사용하며 테스트 산출물은 `Temp/` 아래에만 쓴다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-reliable-battle-channel.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-battle-reconnect.ps1
```

- 채널 검사: 순서 역전, 중복, ACK 유실, 재전송, 재진입, 버퍼 한계 등을 검증한다.
- 복구 검사: 실제 복구 제어 소스를 읽고 Unity/Fusion 및 비동기 실행 환경을 모사한다. 양방향 인증·복구, 누락 메시지, PlayerRef 변경, 공격 처리 중 복귀 차단, 상태 불일치, 위조 응답, 유예 만료, 종료 및 다음 판 초기화를 검증한다.
- 이 검사는 실제 Photon 연결 및 Unity 화면 재생 검증을 대신하지 않는다.

## 실기기 확인 항목

같은 p4 빌드 두 대로 다음을 확인한다.

- 입력 대기 중 한 기기의 네트워크를 끊고 30초 안에 복구: 원래 상대·카드·남은 생각 시간으로 계속한다.
- 공격, 처형 추가 공격, 사망 및 카드 보충 중 각각 끊었다 복구: 공격·카드 보충이 중복되지 않고 양쪽 보드가 일치한다.
- 상대 앱 강제 종료 후 30초 대기: 연결이 유지된 기기에서 AI 인수한다. 끊긴 기기의 로컬 실패는 무효 종료한다.
- 양쪽 네트워크 끊김, 방 소멸, 30초 초과: 영구 대기나 새 방 생성 없이 종료한다.
- 재접속 대기 중 전투 종료·로비 복귀 후 다시 매칭: 이전 재시도·오버레이·메시지가 새 판에 적용되지 않는다.
- 세로 화면과 실제 폰트에서 재접속 안내 및 남은 초가 표시되는지 확인한다.
