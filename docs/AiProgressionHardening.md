# 성장 수단 확장 대비 AI 난이도 상향안

> 초반 유지 방침은 후속 지시로 변경했다. 티어 0~5와 모험 1~8의 최신 값은 [초반 AI 난이도 추가 상향](AiEarlyHardening.md)을 따르며, 중후반은 아래 값을 유지한다.

2026-09-16. 향후 유료재화·이벤트 등 성장 수단 추가를 고려한 임시 콘텐츠 성장 기준이다. 현재 유료재화의 상품 구성·무료 공급량·강화 도달 기간이 정해지지 않아 결제액이나 며칠차 플레이를 가정하지 않았다. 현재 실제 출시된 성급·한계돌파 범위만 사용한다.

## 변경 원칙

- 카드 자체 체력·키워드·덱 구성·보상·강화 비용은 유지했다. AI 성장값만 상향했다.
- 브론즈와 실버 초반(티어 0~5)은 유지한다. 티어 6부터 3성 주력 수를 늘리고 골드 후반부터 한계돌파를 배정한다.
- 기존 성장값을 낮추지 않으며 같은 덱은 티어가 오를 때 성장 단계가 내려가지 않는다. 승급전은 같은 티어 일반전 이상이다.
- 모험 1~8 유지, 9~22 전원 2성, 23~24 전원 3성. 시너지 조합은 기존 덱 그대로다. 3성 일반 추가타는 없다.
- 마지막 두 모험은 전원 동시 성장하는 현 계약 때문에 HP 상승폭이 크다. 추후 보스 한 장만 먼저 강화하려면 별도의 모험 카드별 성장 계약이 필요하며 이번에는 스키마를 변경하지 않았다.

## 검증·반영 상태

- 실제 서버 TypeScript 파서·스냅샷 생성·재채택 검증 통과: 46덱, 랭크 160프로필, 모험 24노드.
- 0~1000점 1001개 지점의 상대 선택, 같은 덱의 티어별 성장 비감소, 승급전 성장≥일반전, 한계돌파는 최대 성급에서만 적용되는 조건을 검증했다.

- RankAiEncounter 132행, AdventureChapter 8행 변경. ID·컬럼·덱 참조·카드 구성·입장 조건 보존.
- 로컬 CSV만 수정했다. 서버 공개본·Google Sheet·SpecData.bytes·생성 C#은 갱신하지 않았다.
- 실제 승률·클리어 시간·무료 재화만으로 도달하는 일수는 미검증이다. 재화 공급안 확정 뒤 무과금/성장 가속 계정별 성급 도달 기간과 재도전 횟수로 재조정해야 한다.
