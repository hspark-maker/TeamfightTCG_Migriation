# 가이드 미션 기반 자율 온보딩 PRD

## Overview

FTUE 종료 후 가이드 미션을 따라 카드 강화 → 키워드 이해 → 시너지 해금 → 돌보미 조합 준비 → 덱 활성화 → 모험으로 이어지는 자율 온보딩을 제공한다. 미션은 다음 목표를 제시하고, 튜토리얼은 조작을 안내하며, 해금 인트로는 방금 열린 기능의 의미를 설명한다.

2026-09-14 사용자 확정. 핵심 연결은 **guide.05의 시너지 해금 설명에서 guide.06의 돌보미 카드 구성으로 자연스럽게 이어지는 것**이다. 기존 가이드 미션의 내용·순서·완료 조건·보상은 유지한다.

상용 패턴 근거:

- MARVEL SNAP은 튜토리얼 이후 랭크 플레이 목표와 강화가 다음 보상으로 이어진다는 안내를 제공한다. 성장 행동의 의미를 해당 순간에 설명하는 방식을 적용한다. [공식 패치 노트](https://marvelsnap.com/patch-notes-may-19th-2026/)
- 하스스톤은 입문 진행과 소개 퀘스트를 함께 운영한다. 플레이 목표와 학습 안내가 서로 보완하는 구성을 적용한다. [공식 신규 플레이어 안내](https://news.blizzard.com/en-gb/article/24166335/launch-into-heroes-of-starcraft)

## Goals

- FTUE 종료 후 가이드 미션을 다음 진행 경로로 인지시킨다.
- 강화 미션의 이동과 기존 강화 튜토리얼을 연결한다.
- 키워드 해금 순간에 새 능력의 의미와 사용 방식을 설명한다.
- guide.05에서 시너지 해금과 활성화의 차이를 이해시킨다.
- guide.05의 설명 마지막에 guide.06의 돌보미 카드 3종을 다음 목표로 제시한다.
- guide.06에서 조합 준비 상태를 확인하고 실제 덱 활성화와 모험 활용으로 이어간다.
- 안내 중단·재접속·소급 달성이 미션 진행과 보상 수령을 막지 않게 한다.

## Out of Scope

- 기존 미션 목표·대상 카드·순서·보상·서버 판정 변경.
- 카드 지급, 성장 비용, 키워드·시너지 수치 변경.
- FTUE 전투 구성 및 졸업 조건 개편.
- 미션 트래커·카드 상세 화면의 전면 디자인 변경.
- 신규 서버 저장 스키마, 서버 배포, 시트 업로드, SpecData.bytes 갱신.
- 팀 공유 지침 수정.

### 미션 계약과 설명 문구

- guide.05는 현재 CSV 기준 보유 카드 1장 2성 이상 도달이다. 과거 PRD의 일반적인 진화 1회 표현으로 조건을 되돌리지 않는다.
- guide.06은 별토리(id 3)·솜구름몽(id 4)·포슬램(id 1)을 모두 보유하고 2성 이상으로 성장시키는 미션이다. 덱 편성 없이도 완료된다. 이 조건을 유지한다.
- guide.06 달성 시에는 **조합 준비 완료**, 실제 덱 조건을 만족한 경우에만 **활성화 완료**로 표현한다. 안내를 위해 덱 편성을 미션 완료의 추가 조건으로 만들지 않는다.
- guide.05에서 해금한 시너지가 돌보미가 아니어도 해당 시너지 설명을 먼저 제공하고, 다음 미션의 돌보미 조합으로 연결한다. 모든 시너지를 돌보미로 표시하지 않는다.
- 인트로 마지막 문구의 의미: “별토리·솜구름몽·포슬램을 모두 2성으로 키워 돌보미 시너지를 준비해 보세요.” 카드 3종을 함께 보여주어 다음 미션에서 같은 대상을 알아볼 수 있게 한다.
- guide.06 진행 중 이미 2성인 카드는 준비 완료로 표시한다. 미보유 카드와 보유했지만 성장 부족인 카드를 구분한다. 미보유 카드를 누르도록 강제하지 않는다.
- guide.06 달성 후 문구의 의미: “돌보미 카드가 준비됐어요. 세 카드를 같은 덱에 편성해 보세요.” 이미 실제 활성화 조건을 충족했다면 재편성을 요구하지 않고 활성화된 효과를 확인한다.
- 설명 마지막에는 다음 목표를 예고한다. 미션 전환과 보상 수령은 기존 순서를 유지하고, 설명 확인으로 자동 지급·수령·완료 처리하지 않는다.

### 기존 안내와 통합

- Mission은 목표·진행도·보상·이동 목적지의 진실원으로 유지한다. 안내가 별도 미션 진행도를 만들지 않는다.
- OutgameTutorial.asset을 조작 안내 및 해금 설명의 저작 창구로 사용한다. 설명 문구·순서·단계는 에디터에서 편집 가능하게 한다.
- OutgameTutorialRunner와 Bridge의 기존 자율 안내 진행·완료·중단 경로를 재사용한다. 별도 온보딩 러너를 추가하지 않는다.
- GuidanceCoordinator가 랭크 상승·보상·콘텐츠 해금·미션 컷인·해금 인트로의 표시 충돌을 조정한다. 강화 연출이 진행 중이면 다른 안내가 끼어들지 않는다.
- UnlockIntroOverlay에서 시스템 설명과 실제 효과·데모를 표시한다. 기존 강화 튜토리얼의 waitUnlockIntro는 추가 설명까지 포함해 기다린다. 설명이 끝나기 전에 상세 화면을 닫지 않는다.
- 기존 SynergyIntroduction의 돌보미 개념 소개를 guide.05의 해금 흐름으로 앞당긴다. guide.06에서는 준비 결과·덱 편성·활성화 확인을 담당하여 같은 개념을 반복하지 않는다. 추적 조합 소개는 기존 역할을 유지한다.
- 미션 이동으로 시작하는 첫 강화 조작 안내와 기존 컬렉션 진입 안내는 같은 완료 기록을 사용한다. 첫 강화 샘플은 실제 보유하고 성장 가능한 카드로 선택하며, 카드 8 고정 의존을 제거한다.
- 첫 조작 샘플과 지정 카드 미션의 대상을 구분한다. 다른 카드로 조작을 배웠다고 지정 카드 미션이 달성됐다고 안내하지 않는다.
- 탭 이동 완료 후 안내를 시작한다. 이미 목적지 탭인 경우에도 동작한다. 안내 가능한 카드가 없으면 강제 입력 차단 없이 자유 이동을 유지한다.

### 중단·저장·기존 계정

- 미션 달성과 설명 완료는 별도로 관리한다. 설명을 미루거나 중단해도 기존 미션 진행·수령은 가능하다.
- 최초 개념 설명은 한 번 제공하고, 개별 능력·효과의 재열람은 유지한다. 잠긴 기능을 단순 열람한 것으로 최초 해금 설명을 완료 처리하지 않는다.
- 마지막 설명까지 확인한 경우에만 완료 기록을 남긴다. 화면 이탈 시 입력 차단·강조를 해제하고, 재진입하면 미완료 설명을 다시 시작할 수 있게 한다.
- 미션의 명시적 이동 재요청은 해당 안내의 세션 미루기만 해제한다. 다른 안내의 진행이나 완료 기록을 초기화하지 않는다.
- 기존 튜토리얼 저장 경로를 재사용하며 미션 ID·기존 stepId·완료 기록을 유지한다. 새 설명 기록의 서버 저장·재채택 보존 여부를 검증한다.
- 기존 계정은 다음 관련 행동에서 미완료 설명을 제공한다. 로그인 직후 설명을 몰아서 표시하지 않는다. 소급 달성으로 강화 연출을 거치지 않은 경우에도 관련 미션 진입·기능 재열람 시 설명을 받을 수 있게 한다.
- 이미 guide.06을 달성했거나 돌보미가 활성화된 계정에는 부족한 카드 성장을 다시 요구하지 않는다. 현재 준비·덱 상태에 맞는 확인 단계로 연결한다.
- 긴 설명은 단계로 나누고 기존 인트로의 제목·본문·카드·데모·확인 버튼이 잘리거나 겹치지 않게 한다.

## Acceptance Criteria

- [ ] 기존 가이드 미션 내용·순서·완료 조건·보상이 유지된다.
- [ ] FTUE 종료 후 가이드 미션의 역할과 이동 방법을 안내한다.
- [ ] 다른 탭과 현재 컬렉션 탭 모두에서 미션 이동 후 안내가 정상 시작된다.
- [ ] 카드 8 미보유, 대상 카드 만렙, 안내 가능한 카드 없음 상황에서 진행이 막히지 않는다.
- [ ] 키워드 해금 설명·실제 효과 확인이 끝나기 전에 강화 튜토리얼이 상세 화면을 닫지 않는다.
- [ ] guide.05 인트로에서 시너지 해금과 활성화를 구분하고, 마지막에 guide.06의 돌보미 카드 3종을 소개한다.
- [ ] guide.05에서 돌보미 이외의 시너지가 해금돼도 올바른 효과를 설명한 뒤 돌보미 목표로 이어진다.
- [ ] guide.05 보상 수령 뒤 guide.06이 기존 순서대로 나타나고 카드별 준비 상태가 설명과 일치한다.
- [ ] guide.06은 세 카드 모두 2성 이상 보유만으로 기존대로 완료되며 덱 편성을 추가 요구하지 않는다.
- [ ] guide.06 달성 후 준비 완료와 실제 덱 활성화 완료를 구분한다. 이미 활성화된 덱에는 재편성을 요구하지 않는다.
- [ ] 일반 시너지 개념 설명과 guide.06의 조합 확인이 중복되지 않는다.
- [ ] 화면 이탈·재접속·연타·키워드와 시너지 동시 해금·소급 달성에서도 중복 완료나 입력 잠금이 발생하지 않는다.
- [ ] 설명 완료 여부와 무관하게 기존 미션 달성·수령이 정상 동작한다.
- [ ] 기존 계정의 다음 관련 행동에서 미완료 설명을 제공하고 기존 진행을 되돌리지 않는다.
- [ ] Unity 컴파일·튜토리얼 저작 검증·저장 왕복 검증을 통과한다.
- [ ] 실제 플레이에서 guide.05 → guide.06 → 덱 활성화 흐름과 설명 레이아웃을 확인한다. 미검증 항목은 별도 보고한다.

## Open Questions

없음. 사용자 확정 범위는 guide.05 해금 설명에서 guide.06의 돌보미 구성으로 연결하는 흐름과 기존 미션 내용 유지다. 기존 계정은 다음 관련 행동에서 설명한다는 초안의 권장 정책을 기본값으로 적용한다.

구현 전 확인 사항: 지정 카드의 실제 획득 경로와 관련 저장 기록의 서버 보존을 확인한다. 획득 경로 부족이 발견돼도 이번 작업에서 카드 지급이나 미션 조건을 임의 변경하지 않고 별도 보고한다.
