# 가이드 미션 초반 성장 흐름 변경 PRD

## Overview

초반 가이드를 강화 경험 → 브론즈 2 달성 → 모험·지정 카드 성장으로 재구성한다. 총 15개 미션이며 표시 순서대로 guide.01~guide.15를 사용한다. 이전 버전 수령 기록과의 호환은 고려하지 않는다.

## Goals

| 순서 | 미션 ID | 완료 조건 | 보상 |
|---|---|---|---|
| 1 | guide.01 | 카드 강화 1회 완료 | 조각 10개 |
| 2 | guide.02 | 브론즈 2 이상 달성 | 기존 조각 10개 |
| 3 | guide.03 | 모험 1번 정점 클리어 | 기존 유지 |
| 4 | guide.04 | 별토리·솜구름몽·포슬램 모두 1성 이상 | 기존 조각 40개 |
| 5 | guide.05 | 카드 진화 1회 완료 | 조각 10개 |
| 6 | guide.06 | 별토리·솜구름몽·포슬램 모두 2성 이상 | 기존 골드 50개 |
| 7~15 | guide.07~guide.15 | 기존 조건 유지 | 기존 유지 |

- 지정 카드 목표는 덱 편성 없이 보유·성장 상태로 판정한다.
- 이전 성장과 무료 강화·진화도 인정한다. 잠긴 미션도 달성도를 기록하며 순서대로 수령한다.

## Out of Scope

모험 해금 정책, 성장 비용·연출, 후반 미션 조건·보상, 팀 공유 지침 수정은 제외한다. 서버 배포·시트 업로드·SpecData.bytes 재생성도 제외한다.

## Technical Requirements

- Mission/Reward CSV만 저작한다. 미션 ID는 표시 순서대로 guide.01~guide.15이며 강화는 guide.01, 진화는 guide.05다. 보상 참조도 같은 ID를 사용한다. 패스 경험치는 0이다.
- 변경·신규 이벤트는 Guide.Bronze2Reached / Guide.EnhanceCompleted / Guide.EvolveCompleted / Guide.StarterCardsAtStar1 / Guide.StarterCardsAtStar2이다. 구 조건 카운터를 새 조건으로 이관하지 않는다.
- 서버 rank/current의 bestTierIndex가 1 이상이면 브론즈 2 달성이다. 점수 임계치는 중복 상수로 만들지 않는다. 조회·수령에서 서버 랭크 문서를 읽고 전투 정산에서도 같은 판정기로 영구 달성을 기록한다.
- 지정 카드 ID는 별토리 3·솜구름몽 4·포슬램 1이다. 목표 성급 이상으로 보유한 지정 카드 수를 세며 목표는 3이다.
- 강화 완료는 보유 카드의 shardProgress > 0 또는 기본 레벨 초과, 진화 완료는 기본 레벨 초과 상태로 인정한다. 간식·한계돌파만 진행한 상태는 제외한다.
- 서버 조회·수령·성장 반영에서 같은 상태 판정기를 사용한다. 최고 진행도와 중복 수령 방지는 유지하며 DTO·세이브 슬롯 구조는 유지한다. 이전 버전 미션 ID·수령 기록을 위한 마이그레이션은 추가하지 않는다.
- 랭크 미션 이동은 매치 탭, 강화·진화·지정 카드 목표는 컬렉션 탭이다. 자동 전투·강화는 실행하지 않는다.
- 막 구간은 1~3 / 4~7 / 8~9 / 10~15이다. 돌보미 소개는 guide.06 달성 후 안전한 로비 시점에 덱 없이 효과를 안내한다. 기존 소개 완료 기록과 추적 소개의 덱 강조 흐름은 유지한다.

## Acceptance Criteria

- [ ] 강화 → 브론즈 2 → 모험 1번 순서이며 총 15개다.
- [ ] 브론즈 1은 미완료이고 브론즈 2 이상 도달 기록은 완료다.
- [ ] 지정 카드 3종 모두 목표 성급 이상이어야 완료된다. 다른 돌보미 카드로 대체되지 않으며 덱은 불필요하다.
- [ ] 부분 조각 투입은 강화만, 별 상승은 강화·진화 모두 인정한다. 기존·무료 성장도 인정한다.
- [ ] 현재 미션 ID 기준으로 각 보상은 한 번만 지급한다. 이전 버전 수령 기록과의 호환은 검증 대상에서 제외한다.
- [ ] 구 조건 카운터로 새 조건을 자동 완료하지 않는다.
- [ ] 순차 수령·막 완료·이동·돌보미 및 추적 소개가 정상 동작한다.
- [ ] 서버 판정·수령 회귀, TypeScript 검사, Unity 컴파일·플레이 확인을 수행하고 미검증 항목은 보고한다.
- [ ] CSV 변경과 서버·생성 산출물 미반영 상태를 구분해 보고한다.
