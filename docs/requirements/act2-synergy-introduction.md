## Goals

- 성장 미션 시작 시 시너지의 존재와 성장 목적을 설명한다.
- 도입 온보딩을 **시너지 해금 조건 → 실제 해금 → 시스템 소개**로 연결한다. 앞선 강화 조작·키워드 설명은 반복하지 않는다.
- guide.06 다음에 시너지 덱 실전 미션을 배치한다.
- 신규 미션 시작 시 편성·활성 조건·실전 사용법을 안내한다.

## Out of Scope

- 1막·3막·4막 전체 재설계.
- 시너지 효과·성장 비용·해금 조건 변경.
- 일반 성장 비용 변경·재화 직접 지급. 시너지 도입의 지정 카드 2성 달성 비용만 무료로 지원한다.
- 정식 시트·서버 배포 및 생성 산출물 갱신.

## Technical Requirements

### 1. 미션 활성화 기준

현재 활성 미션은 **순서상 첫 미수령 미션**이다. 선행 미션을 달성했더라도 보상을 수령하기 전에는 다음 온보딩을 시작하지 않는다.

삭제된 guide.04가 다음 미션 활성화나 순차 수령을 막지 않아야 한다. 기존 미션 ID는 보존하고, 신규 미션에는 별도 ID를 부여한다. 삭제 미션 ID를 새 목표에 재사용하지 않는다.

guide.04는 `enabled=0`으로 퇴역한다. 활성 미션의 순서는 `guide.07 → guide.05 → guide.06 → guide.16 → guide.08`이며, 이후 미션의 상대 순서와 기존 수령 기록을 보존한다. 신규 미션 삽입으로 이미 얻은 3·4막 콘텐츠 이용 자격을 회수하지 않는다.

### 2. 성장 미션 도입 온보딩

**guide.05 활성화 → 시너지 소개 → 2성 해금 조건 → 실제 시너지 해금 → 필요 장수·활성화 원리 → 덱 준비**

| 단계 | 전달할 내용 |
|---|---|
| 시너지 존재 소개 | 카드에는 함께 편성했을 때 효과를 내는 시너지가 있다 |
| 해금 조건 설명 | 카드가 2성이 되면 그 카드의 시너지가 해금된다 |
| 시너지 해금 | 보유 카드의 상세로 이동해 2성까지 성장한다. 샤드 투입·길게 누르기 등 강화 조작을 다시 설명하지 않는다 |
| 해금 인트로 | 실제로 해금된 시너지의 효과와 필요 장수를 확인한다 |
| 시스템 소개 | 해금과 활성화는 다르다. 같은 시너지가 해금된 카드를 필요한 수만큼 덱에 편성해야 활성화된다 |
| 마무리 | 덱의 시너지 표시에서 조건·효과를 확인할 수 있음을 알려 주고 같은 시너지 카드 준비로 연결한다 |

이 단계는 **시너지 해금과 시스템 원리 소개**를 담당한다. 실제 덱 편집·저장·전투 실습은 guide.16에서 다룬다.

앞선 「카드 강화」에서 샤드 투입·길게 누르기·진화·키워드 해금을 이미 설명한다. guide.05에서는 해당 설명을 반복하지 않고 시너지 해금 목적에 집중한다. 성장 중 함께 발생하는 기존 키워드 연출은 정상 재생한다.

성장 목표는 **보유 카드 1장 2성 이상**으로 유지한다. 이미 달성한 계정은 강화를 생략하고 시너지 시스템 설명만 재노출한다. 신규 성장 시 실제 해금 인트로 종료까지 기다린다. 사용자 추가 지시에 따라 해당 안내 대상 카드의 2성 달성까지 강화 비용을 무료로 처리한다. 재화를 지갑에 지급하지 않으며, 다른 카드와 2성 이후 강화는 지원하지 않는다.

이전 카드 강화 튜토의 무료권과 독립된 서버 명령 `enhanceSynergyIntroduction`을 사용한다. 서버가 guide.05 활성 상태·카드 소유·대상 카드·성장 목표를 검증한다. **강화 한 번으로 즉시 2성에 도달하며 비용은 0이다.** 0성·1성·일부 샤드 투입 상태 모두 목표까지 남은 전체 샤드를 한 요청에서 채운다. 미리보기와 실제 결과도 2성 기준으로 일치한다. 2성에 도달하면 지원을 종료한다. 새 명령 미배포나 거절 시 기존 유료 명령으로 대체하지 않는다. 실제 계정 적용에는 해당 서버 명령 배포가 필요하다.

해금 대기는 기존 카드 강화 튜토와 같은 `WaitEnhance.waitUnlockIntro`로 처리한다. 별도 `WaitUnlockIntro` 액션은 사용하지 않는다. #67이 실제 인트로 종료까지 기다리고, #68·#69 확인 메시지는 카드 상세의 시너지 영역(`CardDetailSynergyDescription`)을 앵커로, 카드 미리보기(`CardDetailCardView`)를 스포트라이트로 사용한다. 기존 #68 ID는 확인 메시지로 유지해 저장된 재개 위치를 보존한다. 이미 성장한 계정도 설명할 카드 상세 화면을 준비한다.

### 3. 신규 시너지 실전 미션

- 위치: 현재 guide.06 직후, 3막 진입 전.
- 소속: 2막 「시너지 입문」.
- 식별자: `guide.16`, 이벤트 `Guide.CompleteSynergyBattle`, 목표 횟수 `1`.
- 목표: **미션 활성화 이후 시작한 랭크·모험 전투를 시너지 활성 덱으로 1회 완료**.
- 시작 조건: 해당 미션이 현재 활성 미션이 되었을 때.
- 온보딩 흐름: **덱 편집 안내 → 같은 시너지 카드 확인 → 성장·편성 조건 설명 → 활성 표시 확인 → 전투 유도**.

시너지 활성 덱을 아직 만들지 못했어도 온보딩은 시작되어야 한다. 이미 활성 덱이 있으면 재편성을 강요하지 않고 활성 효과 확인부터 이어간다.

**확정 판정:** 서버가 전투 시작을 승인할 때 해당 미션이 활성 상태이고, 승인된 덱에 활성 시너지가 하나 이상 있으면 집계 자격을 기록한다. 해당 랭크·모험 전투의 정상 완료 시 승리·패배·무승부 모두 인정한다. 미션 활성화 이전에 시작한 전투·취소 전투는 인정하지 않는다. 전투 후 변경한 덱으로 과거 전투를 판정하지 않으며 동일 전투의 중복 정산은 진행도를 증가시키지 않는다.

시너지 효과의 실제 발동 횟수는 별도 조건이다. 이번 목표를 기존 `TriggerSynergy` 횟수 미션으로 대체하지 않는다.

보상은 기존 guide.04의 **샤드 40개**를 guide.16으로 옮긴다. 수령 키는 신규 미션 ID이므로 과거 guide.04 보상 수령 여부와 무관하게 guide.16을 달성한 계정에 1회 지급한다.

## Acceptance Criteria

다음 항목은 향후 구현 완료 기준이며, PRD 확정이나 문서 저장만으로 완료 처리하지 않는다.

- [ ] 2막 이름이 트래커·미션 목록에서 「시너지 입문」으로 표시된다.
- [ ] 지정 3종 1성 미션이 제거되고 다음 미션으로 정상 진행된다.
- [ ] 성장 미션 **활성화 시점**에 시너지 도입 온보딩이 시작된다.
- [ ] 앞선 강화 조작 설명을 반복하지 않고 시너지 해금 → 시스템 소개 → 덱 준비 순서로 진행된다.
- [ ] guide.06 다음에 신규 시너지 실전 미션이 활성화된다.
- [ ] 활성 덱이 없는 계정도 편성 방법을 안내받는다.
- [ ] 시너지 비활성 덱으로 플레이한 전투는 신규 미션에 집계되지 않는다.
- [ ] 동일 전투의 중복 보고로 진행도가 중복 증가하지 않는다.
- [ ] 안내 중단·재접속·선행 성장 계정에서도 진행이 막히지 않는다.
- [ ] 삭제 미션의 기존 수령 기록과 신규 미션 보상이 충돌하지 않는다.
- [ ] 확정된 성장 목표와 전투 인정 기준이 화면·데이터·서버 판정에서 일치한다.

## 확정 결정

2026-09-15 구현 계획 승인으로 다음 기준을 확정했다.

1. **성장 목표:** 보유 카드 1장 2성 이상 유지.

5. **시너지 인트로:** 이미 성장·해금한 계정에는 시너지 시스템 설명만 재노출. 미달 계정의 안내 대상 카드는 2성까지 무료 강화한다. 강화·키워드 조작 교육은 앞선 튜토리얼이 담당한다.

## 구현 반영

- CSV: guide.04 비활성화, guide.16 추가, 2막 이름·순서·샤드 40개 보상 연결.
- 온보딩: 성장 도입과 덱 실전 안내를 별도 자율 챕터·완료 기록으로 추가. 선행 성장·활성 덱은 불필요한 행동을 생략한다.
- 서버: 최초 덱 승인에 집계 자격을 고정하고 정상 전투 정산에서 가이드 진행도에 반영한다. 기존 가이드 수령 기록과 콘텐츠 접근을 보존한다.
- 동일 에셋의 기존 모험 안내에 중복되던 stepId 52는 첫 스텝에 유지하고 뒤쪽 스텝만 81로 재부여했다. 신규 챕터는 62~80, 다음 발급 번호는 82다.
- 검증: 서버 빌드·관련 린트 및 가이드 회귀 25개 통과. Unity 컴파일과 저작·미션 진행·저장 왕복·챕터 분리 검증 4종 통과. 저작 검증은 `Tools/Tutorial/Validate Act 2 Synergy Introduction`에서 다시 실행할 수 있다.
- 반영 경계: 정식 시트·서버 배포·SpecData.bytes는 미반영. 실제 서버가 새 Mission·Reward를 제공한 뒤 플레이 모드에서 위 Acceptance Criteria를 확인한다.

### 에디터 로컬 플레이 진입

1. Unity에서 Play를 실행하고 첫 시작 튜토리얼을 완료한 계정으로 로비 초기화를 마친다. 로그인·초기 데이터 로딩에는 서버 연결이 필요하다.
2. 진행 중인 안내·연출을 마치고 팝업을 닫는다.
3. `Tools/Tutorial/Play Test Act 2 Onboarding`에서 선택한다.
   - **성장 도입 — 직접 강화·해금 연출:** 보유 카드를 미강화 상태로 두고 실제 강화 UI로 2성까지 진행한다. 일부 샤드 투입만으로 안내를 완료하지 않는다.
   - **성장 도입 — 이미 2스타 달성:** 보유 카드가 2성인 상태에서 설명만 재생한다.
   - **시너지 실전 도입 — 덱 편집·저장:** 전체 카드의 시너지를 해금하고 빈 덱에서 시작한다. 카드 6장과 활성 시너지를 구성해 저장한다.
4. 종료하거나 다른 조건을 시험하려면 Play를 중지하고 다시 실행한다.

테스트 시작 시 `OnboardingPlayTest`가 현재 세이브를 복제하고 가상 재화를 준비한다. 업로드와 서버 명령은 Play 종료까지 차단한다. `GuidanceCoordinator.PlayTest` → `OutgameTutorialRunner.FirePlayTest` → 기존 브리지·저작 스텝을 사용하며, 실제 미션 활성 조건과 기존 완료 기록을 우회한다. 테스트 진행·성장·덱 변경은 계정에 저장되지 않는다. 실제 전투 집계·미션 활성화·보상 지급은 이 진입점의 검증 범위가 아니다.

로컬 검증: Unity 컴파일, 테스트 창 열기·Edit 모드 진입 거절, 기존 검증 4종 및 `Tools/Tutorial/Validate Onboarding Play Test` 통과. 마지막 검증은 가상 강화의 부분 투입·진화 경계·비용·키워드 해금·원본 세이브 보존·서버 명령과 늦은 응답 차단을 검사한다. 실제 UI 클릭으로 세 챕터를 끝까지 진행하는 Play 모드 검증은 별도다.
