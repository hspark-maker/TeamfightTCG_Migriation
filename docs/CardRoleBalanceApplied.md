# 카드 역할·등급 체력 밸런스 1차 반영

2026-09-16. 사용자의 최신 지시: 도발 체력을 올리지 않고, 모든 카드에 키워드를 강제하지 않으며, 무키워드 카드에 높은 체력을 배분한다. 등급에 따른 차등은 유지한다.

**로컬 Card CSV에 반영한 설계값이다. 자동 대전 승률 검증을 완료한 값은 아니다.** 새 효과·전투 코드·서버·생성 산출물은 변경하지 않았다. 이전 `CardHpBalanceProposal.md`의 도발 체력 상향안과 `CardBalanceProposal.md`의 전 카드 키워드 부여 원칙을 대체한다.

## 적용 기준

- 여기서 무키워드 일반 공격수와 희귀도 Common(일반 등급)은 서로 다른 개념이다. 일반 등급과 희귀 등급에 모두 무키워드 공격수를 둔다.
- 솜구름몽·바위콩·꿀꿀비·단풍꼬리의 최근 추가 키워드를 제거하고 모든 시너지 배정은 보존했다. 무키워드 일반 등급은 3성 HP 18, 희귀는 20이다.
- 도발을 유지하는 8장의 기본 HP와 성장 증가분은 모두 변경 전과 동일하다. 도발 반감을 체력 상향의 근거로 사용하지 않는다.
- 회복과 반격 회피의 가치가 있는 힐러·원거리는 낮은 체력으로 배분한다. 힐러는 일반 등급 3성 HP 13~14, 희귀 15~16이다.
- 무쌍의 3성 HP는 일반 16, 희귀 17, 신비 18, 신화 19; 처형은 일반 16, 희귀 17, 신비 18이다. 교활은 일반 14~15, 신비 17이다.
- 불사는 기존 키워드 강화 HP를 받지 않는 점을 고려해 일반 15, 신비 17, 신화 19로 둔다. 지원 키워드 강화가 높은 환경과 별도 비교해야 한다.
- 등급 차등은 역할별 기준에 적용한다. 기존 도발은 보존 예외이므로 모든 역할·성급에서 모든 상위 등급 카드의 HP가 반드시 높다는 뜻은 아니다.
- 후속 지시에 따라 무키워드 카드의 3성 추가타는 비활성화했다. 추가타는 추후 도입 예정이며, 이번 체력 조정값은 그대로 유지한다.

## 확인 결과와 남은 검증

- 40장·ID·열 계약 유지, 기존 시너지·등급·해금 조건 보존(무키워드 전환 4장의 해금값만 0으로 정리).
- 모든 성장 증가분 양수, 누적 HP와 증가분 일치, 키워드·시너지 참조 유효.
- 도발 유지 8장 체력 곡선 불변, 원거리·힐러 체력 하향과 무키워드 체력 상향 확인.
- 시너지 미지정 카드는 0장, 무키워드는 의도적으로 4장이다.
- 실제 밸런스 확정에는 선후공·드로우·성급·키워드 강화 수준별 대전이 필요하다. 특히 무키워드는 키워드 강화 HP를 받지 않으므로 강화 0/5/10 환경을 나누어 비교해야 한다.
- 높은 체력의 바위콩+덩치, 단풍꼬리+유산, 꿀꿀비+낙인 조합을 우선 확인한다. 2~3힐러+도발의 오버힐 누적도 검증 대상이다.
- HP만으로 같은 능력 카드의 고유 행동이 생기지는 않는다. 일부 카드의 초반·후반 성장 차이는 두었지만 완전한 역할 차별화를 검증했다는 뜻은 아니다.
- 서버 업로드 대상은 Card 표다. `SpecData.bytes`와 자동 생성 C#은 변경하지 않았고 업로드·배포하지 않았다.
