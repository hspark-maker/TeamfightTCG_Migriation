# AI 덱 밸런스 반영 (2026-09-16)

> 후속 초반 조정으로 모험 1번의 카드 2장도 교체했다. 해당 구성과 초반 성장값은 [초반 AI 난이도 추가 상향](AiEarlyHardening.md)이 최신이다.

> 덱 구성은 이 문서를 따르며, 이후 상향된 AI 성급·한계돌파 값은 [성장 수단 확장 대비 난이도 상향안](AiProgressionHardening.md)이 최신이다. 아래 성장값·HP 합은 상향 전 기록이다.

역할별 체력·등급 차등, 무키워드 고체력 카드, 3성 일반 추가타 비활성 기준의 1차 저작값이다. 실전 승률을 검증한 최종 밸런스는 아니다.

## 반영 범위

- 랭크 22덱과 모험 24덱을 조정했다. 모든 덱은 서로 다른 6장이며 무키워드 공격수를 포함한다.
- 모험 1~12 전용 덱 12개를 신규 ID 35~46으로 추가했다. 기존 ID는 보존하고 모든 모험 덱은 티어 999로 랭크에서 제외했다.
- 랭크 160개 프로필의 ID·전투 종류·한계돌파·강조 슬롯·등장 구간·가중치는 보존했다. 그중 35개 프로필의 레벨 배분을 조정하고 메모는 실제 구성으로 갱신했다.
- 초반 비늘 덱에 몰린 3성 3장을 주력 1장으로 줄였다. 티어 6 신규 무쌍 덱의 보조는 2성으로 맞추고, 티어 7~10은 주력 3성 1장·보조 2성 5장으로 연결했다. 티어 11 이후 성장값은 유지했다. 일반전 후보 평균 HP는 티어 4~6에서 55, 티어 7~12에서 58로 이어진다. 이는 성장 배분 검증이며 승률 동등성을 뜻하지 않는다.
- 브론즈 첫 단계는 실제 Lv1 키워드/시너지 미활성이다. deck_13의 슬롯3·4는 철갑몽치·마그네토스, deck_14의 슬롯3·5는 버섯냥·깜밤이로 초반 시너지 해금과 성장 슬롯을 맞췄다.
- 도발·힐러는 덱당 각각 최대 2장, 대부분 0~1장이다. 치유 테마는 2힐러를 허용한다. 순서는 셔플 전 저작 순서이므로 전열 고정을 보장하지 않는다.
- 모험 node_03은 내부 Lv1→2, node_04는 Lv3→2로 바꿔 첫 장의 1→2→1→3→2 왕복을 제거했다. 나머지 레벨·입장 점수·보상은 유지했다. node_15부터 Lv3 시너지가 활성화된다.
- 신화 카드는 랭크 16티어 이후 deck_09와 모험 18/20/24번에 한 장씩 배치했다. 후반 모험에는 유산4·낙인5·비늘4·덩치4 이상의 완성 조합을 사용한다.

## 반영 상태

- 로컬 CSV만 변경했다. 업로드 대상: AIDeck, RankAiEncounter, AdventureChapter. 최신 Card도 아직 미발행이면 함께 발행해야 한다.
- AIDeckCard는 폐기된 표이므로 수정하지 않았다. 서버·시트·SpecData.bytes·자동 생성 C#은 갱신하지 않았다.
- 무키워드 추가타 비활성은 앞선 코드 변경이며, 앱과 서버 재생 코드에 새 빌드가 반영되어야 한다.
- 실제 승률·Unity 플레이는 미검증이다.

## 검증 결과

- 실제 서버 TypeScript 파서·스냅샷 생성·재채택 함수로 46덱, 랭크 160프로필, 모험 24노드 검증 통과.
- 덱당 서로 다른 Live 카드 6장, 모든 ID·참조·컬럼 계약, 성장 범위와 한계돌파 조건 검증 통과.
- 0~1000점 1001개 지점에서 일반전/승급전 후보 선택을 확인했다. 실제 승급 경계 259·419·579·739점도 포함한다.
- 같은 덱의 티어 상승 시 카드별 성장 비감소, 승급전 성장≥동일 티어 일반전, 입문 키워드 미활성, 비늘·추적 해금 조건을 확인했다.
- 모든 모험 덱이 랭크 후보와 분리되어 있고, 첫 모험은 키워드 미활성·15번부터 시너지 활성인 스냅샷을 확인했다.
- 덱 역할 구성과 데이터 연결 검증이다. 선후공·셔플·플레이어 덱을 포함한 자동 대전 승률 검증은 수행하지 않았다.
