# BalloonPeng 아이소메트릭 모션 시제품

원본 펭귄의 둥근 몸, 파란색, 하늘색 스카프와 머리 깃을 유지하고, 두 번째 참고 이미지의 위에서 내려다보는 시점과 굵은 윤곽선을 반영한 시제품입니다.

## 사용

현재 걷기 결과는 `Cutout/BalloonPeng_Cutout_Preview.unity`입니다. 기존 한 장 메시의 배 일렁임을 제거하기 위해 몸통·양날개·양발을 분리한 버전이며, 자세한 내용은 `Cutout/README.md`에 있습니다. 아래의 이전 메시 걷기는 비교용으로 남겨 두었습니다.

- `BalloonPeng_Preview.unity`를 열고 Play를 누르면 대기 모션을 확인할 수 있습니다.
- `BalloonPeng_Isometric.prefab`을 월드 씬에 배치하면 연결된 Animator가 Idle을 반복합니다.
- 걷기: `BalloonPeng_Walk_Preview.unity`를 열고 Play를 누릅니다. `BalloonPeng_Walk.prefab`과 `Walk.anim`은 파닥임과 별도의 에셋입니다.
- 카메라는 캐릭터 평면의 앞쪽(음수 Z)에서 봅니다. 위에서 내려다보는 시점은 그림에 포함되어 있습니다.
- 기존 카드 이미지 교체나 전투 화면 연결은 하지 않았습니다.

## 모션과 한계

- 2.4초 동안 양 날개를 세 번 파닥이는 반복 동작. 발을 포함한 몸 전체가 살짝 떠올랐다 내려오며, 몸 기울임과 머리 깃·스카프가 뒤따릅니다.
- 날개 회전은 먼 쪽 ±20도, 가까운 쪽 ±22도이며, 떠오르는 높이는 최대 0.2 Unity 단위입니다.
- 투명 PNG 한 장을 격자 메시로 만들고 실제 본과 정점 가중치로 변형합니다. 기본 Unity `SkinnedMeshRenderer`를 사용합니다.
- 날개는 어깨에서 끝으로 갈수록 본을 더 따라가도록 가중치를 조정했습니다. 한 장의 그림을 변형하므로 날개를 완전히 접거나 뒤집는 동작, 방향 전환, 큰 보폭으로 발의 숨겨진 면을 드러내는 동작에는 추가 아트가 필요합니다.
- 날개와 스카프의 중첩 영역은 두 본을 연속 혼합하며, 정점당 최대 네 가중치를 Unity 규약에 맞춰 내림차순으로 저장합니다.
- 아트는 기본 제공 이미지 생성 도구로 만들었으며, 사용한 프롬프트는 `GenerationPrompt.txt`에 보관했습니다.
- 원본 카드 PNG와 참고 사진은 수정하지 않았습니다.

## 저작

`Editor/BalloonPengPrototypeBuilder.cs`에 본 위치, 가중치 범위와 모션 수치가 있습니다. 생성 메뉴는 `Tools > Art Prototypes > Build BalloonPeng Isometric`입니다. 생성된 에셋은 Unity Inspector와 Animation 창에서도 편집할 수 있습니다.

이 메뉴는 최초 생성용이며 기존 산출물이 있으면 덮어쓰지 않고 중단합니다.

기존 시제품에 파닥임을 반영할 때는 `Tools > Art Prototypes > Update BalloonPeng Flutter`를 사용합니다. 클립과 메시의 GUID를 유지하여 프리팹·씬 연결을 보존합니다.

걷기 생성 메뉴는 `Tools > Art Prototypes > Build BalloonPeng Walk`입니다. `Update BalloonPeng Walk`는 걷기 클립과 전용 메시만 갱신합니다.

## 걷기

- 같은 방향을 보며 양발을 번갈아 내딛는 제자리 걷기입니다. 월드 좌표로 이동시키는 로직은 포함하지 않습니다.
- 한 주기는 1.2초이며 두 걸음입니다. 발은 최대 0.055 단위 들리고, 몸은 좌우 최대 3도 기울어집니다. 지지하는 발의 본은 몸의 상하 움직임을 상쇄합니다.
- 걷기 전용 리깅은 기존 여섯 본에 양발 본을 더한 여덟 본입니다. 발 박자에 맞춘 몸의 상하 움직임·뒤뚱거림과 날개·깃·스카프의 흔들림을 포함합니다.
- 파닥임의 기존 메시·클립·프리팹·컨트롤러·씬은 그대로 사용합니다.
- 움직이는 미리보기: 프로젝트 루트 `output/balloonpeng-walk/BalloonPeng_Walk.webp`.

### 걷기 검증

- Unity 컴파일·생성·Animator 재생과 양발 교대 확인. 코드 검수 발견 없음.
- 본 8개, 정점 2,401개. 가중치 합 최대 오차 `4.10e-8`.
- 48개 자세에서 전체 메시 삼각형 뒤집힘 0개. 루프 시작·끝 변형 정점 차이 0.
- 실제 본 변형을 Unity 카메라로 48프레임 렌더링해 40fps 무손실 animated WebP로 인코딩.
- 생성 전후 파닥임 메시·클립·프리팹·컨트롤러·씬 5개 파일의 해시 일치 확인.

## 파닥임 검증

- Unity에서 생성 도구 컴파일 및 실행 성공, 코드 검수 발견 없음.
- 본 6개, 정점 2,401개. 정점 가중치 합의 최대 오차 `2.98e-8`.
- 0초와 2.4초의 변형 메시 정점 차이 `0`: 반복 경계 일치.
- 실제 본 변형을 48개 시점에서 Unity 카메라로 렌더링하고, 픽셀 편집 없이 무손실 animated WebP로 인코딩했습니다(서로 다른 이미지 47개, 대칭 자세 1개 중복).
- 48개 자세에서 불투명 영역(삼각형 중심 알파 > 0.25)의 삼각형 뒤집힘 0개. 투명 여백의 메시 변형은 이 시각 검증에서 제외합니다.
- 업데이트 전후 메시·클립 GUID 유지 확인, BalloonPeng 관련 Unity 콘솔 오류 없음.
- 움직이는 미리보기: 프로젝트 루트 `output/balloonpeng-flutter/BalloonPeng_Flutter.webp`. 이전 작은 대기 모션 미리보기는 `output/balloonpeng-isometric/BalloonPeng_Idle.webp`에 남아 있습니다.
